# 診断結果の組み立て方と、文面の決まり

> 結果はAIを使わず、あらかじめ用意した文面の「部品」を、回答に合わせて選んで組み立てます（2026-10-24 に、AI（Gemini）で作る形から切り替えました）。
> 組み立てるプログラムは `src/lib/diagnose.ts`、部品は `src/data/catalog/`、部品の形と書き方の決まりは `src/data/catalog/types.ts` です。
> このファイルと `types.ts` の決まりはそろえておきます（直すときは両方）。

## 1. 全体の流れ

1. 回答（選択肢のID）を確かめる（`src/lib/answers.ts` の validateAnswers）
2. 1・1-2 で、仕事のタイプ（6つ）と仕事の内容（24個）が決まる
3. 仕事の内容ごとの「顕在型」から2つ、仕事のタイプごとの「潜在型」から1つを、点数の高い順に選ぶ（3章。結果は全部で3件）
4. 二つ名・要約・強みハッシュタグ・得意な市場などの文面を、選んだ回答の言葉を「」で引用しながら組み立てる（4章）

すべてブラウザの中で行い、回答はどこにも送りません。同じ回答からは、いつも同じ結果になります。

## 2. 部品の置き場所と数

| ファイル | 仕事のタイプ |
|---|---|
| `talk.ts` | 人と話す仕事（営業・接客・サポート） |
| `plan.ts` | 企画・発信する仕事（企画・マーケ・広報） |
| `office.ts` | 組織を支える仕事（人事・経理・総務・公務員） |
| `create.ts` | つくる仕事（IT・デザイン・制作） |
| `care.ts` | 人をケアする・教える仕事（医療・介護・教育） |
| `field.ts` | 現場を動かす仕事（製造・物流・建設） |

1ファイルに入っているもの：

- **仕事の内容4つ**（details）：それぞれ、二つ名の後ろ半分（role）・本業のタグ・ナレッジ（いまは画面に出さない）・得意な市場の名前・伸ばす強み・STEP5 の4つの答えごとのタグとナレッジ・**顕在型の仕事5つ**（jobs）
- **潜在型（仕事の外の経験 × 本業）**（hidden）：設問6の経験5つそれぞれに3つ＝15件
- **潜在型（本業の延長）**（extension）：設問6が「特にない」人向けに3件

STEP5（深掘り）の質問と選択肢、引用の言い回しは `src/data/questions.ts` の JOB_FAMILIES にあります。

## 3. 仕事の選び方（点数）

部品の仕事にはそれぞれ「根拠になる回答」（evidence。設問2〜6の選択肢ID）と、仕事の形（前に出るか裏方か・会社相手か個人相手か・契約の形）が書いてあります。点数は次の足し算です。

| 見るもの | 点 |
|---|---|
| 根拠の回答を選んでいる | 頼まれること（3）＝3点、いちばんの自信（2）・関わる相手（5）・経験（6）＝2点、やる気（4）＝1点。1つ目の根拠なら＋0.5 |
| STEP5 の答えに合う（顕在型だけ） | ＋5 |
| 働き方の好み（8-1〜8-3）と仕事の形が合う | 1段につき ±0.75（真ん中なら動かない）。8-3 は、月額継続＝継続側・単発納品＝単発側（時間単価・成果報酬は動かない） |
| 使える時間が週3時間未満で、毎週の定例が要る仕事（regular） | 点数にかかわらず後ろへ回す（＝結果に出さない。足りないときは、同じタイプのほかの仕事の内容から定例の要らない仕事を補う） |
| 「収入を増やしたい」（7-1 は2つまで選べる。2つ選んだら、下の4行のうち当てはまるものを両方足す） | 市場ニーズ◎＋2、○＋1 |
| 「将来の独立に備えたい」 | 月額継続＋1.5。3つに月額継続が1つも無ければ、顕在型の3〜5番目の月額継続（時間が少ない人には regular 以外）と2位を入れ替える。入れ替えられる仕事が無いときはそのまま（点検では「注意」） |
| 「社会や地域の役に立ちたい」 | 地域・NPO・学校などの役に立つ仕事（social）＋2 |
| 「好きなことを仕事にしたい」（潜在型だけ） | 経験が「SNSやブログでの発信」「趣味・スポーツ・ものづくり」なら＋2 |
| 潜在型で、その仕事の内容にとくに合う（details） | ＋3 |

- 顕在型：仕事の内容の部品から上位2つ（1・2位）。2026-11-11 に案件の少ない仕事（△）を外して部品が2つに満たない仕事の内容があるので、足りない分は同じタイプのほかの仕事の内容の部品から補う（深掘りの答えとの一致は見ない）
- 潜在型の部品が0になった経験もある。その経験を選んだ人には、本業の延長から出す
- 潜在型：経験を2つ選んだ人は、それぞれの経験のいちばん上を比べて点数の高いほう。1つの人は、その経験のいちばん上。「特にない」の人は本業の延長のいちばん上（3位）
- 点数が同じなら、部品に書いた順

**強み活用度**：顕在型は、STEP5 の答えに合うか、頼まれること・いちばんの自信が根拠に入っていれば◎、それ以外は○。潜在型は、頼まれること・いちばんの自信が根拠に入っていれば◎、その仕事の内容向けではない（details に入っていない）なら△、それ以外は○。

**市場ニーズ・契約の形**：部品に書いた値をそのまま出す。

## 4. 文面の組み立て

| 項目 | 組み立て方 |
|---|---|
| 二つ名 | 頼まれること（なければ、いちばんの自信）から決まる前半 ＋ 仕事の内容の role（例：「本音を引き出す」＋「採用の伴走者」） |
| 要約 | 頼まれること・やる気・STEP5（なければ仕事の内容）・仕事の外の経験を「」で引用した2〜3文 |
| 強みハッシュタグ | 本業＝仕事の内容のタグ＋STEP5 のタグ → 顕在型＝選んだ顕在型の仕事のタグのうち残り → 潜在型＝選んだ潜在型の仕事の1つ目のタグなど、の順に8つまで（この3つの分け方は skill_map として持つが、画面には出さない。強みの3要素と3層マップの欄は 2026-10-24 に外した） |
| 得意な市場 | 2軸は働き方の好みから自動で選ぶ（questions.ts の pickMarketAxes）。名前は「仕事の内容の field（会社向け／個人向け）＋を前に立って／裏方で／そばで支える仕事」。説明は選んだ2軸の向きで決まる文 |
| 向いている理由 | 選んだ回答の引用2つ ＋「〜ので、」＋ 部品の because。引用は、STEP5 の答え（その仕事に合うとき）→ 潜在型の経験 → 根拠の回答 → STEP5 の答え（なければ仕事の内容）→ いちばんの自信 → やる気、の順に2つ |
| 注意点 | 仕事の内容の caution、選んだ仕事の caution、週3時間未満なら「1件だけ受けて確かめる」 |
| 回答が少ない | 頼まれることと仕事の外の経験が、どちらも「特にない」なら confidence を low にして、画面に「結果が大まかになっているかもしれません」を出す |

## 5. 部品の書き方の決まり

`src/data/catalog/types.ts` の冒頭と各項目の説明が正です。要点：

- **ニッチな仕事**＝「できること」×「届ける相手（業界・対象）」×「届け方」のうち2つ以上を具体的に絞った仕事。職種名は「対象＋仕事内容」で25字以内（✗ Webライター → ○ 製造業BtoB企業の導入事例インタビューライター）
- 実在する（日本で複業・業務委託として発注されうる）・ライバルが少ない・小さく始められる（今週の一歩は30分〜2時間）
- 海外で広がっている働き方も入れてよい。そのときは「海外では『〇〇』と呼ばれ、広がっている働き方です。」のように一言添える
- 中学生にもわかる言葉。横文字は必要なものだけ。前向きに
- 「副業」ではなく「複業」と書く（2026-10-26 にそろえた）。keywords（案件を探す検索語・いまは画面に出さない）だけは、募集サイトで実際に引く言葉なので「副業」のままでよい。`npm run check:results` が見る
- **お金**：金額や「稼げる」「儲かる」「確実に」「誰でも」「高収入」「楽して」は書かない
- **資格や許可が必要な仕事は入れない**：税務書類の作成・税務相談、官公署に出す書類や補助金申請書の作成代行、社会保険の手続き代行、登記、法律相談・契約書の作成代行やリーガルチェック、医療・診断・治療にあたる行為、投資の助言・銘柄のおすすめ・金融商品の勧誘、保険の募集、有料の人材紹介・転職のあっせん、不動産の売買・賃貸の仲介、旅行の手配・販売、健康食品やサプリ・体づくりで効き目をうたうこと。強みを活かしたいときは「資格者のサポート（資料集め・情報整理・事務）」や「制度をわかりやすく伝える発信・講師」の形にする
- 初期費用や高額講座が前提のもの、情報商材、ネットワークビジネス、アフィリエイトだけのもの、本業の会社の顧客や社外秘の情報を使うものも入れない
- 「〇〇はしない」のような断り書きは、本文ではなく caution に書く
- 向いている理由の後半（because）には「ので」「から」を入れない（前に「〜ので、」が付くため）。前に引用される回答を言い直さない（潜在型は「仕事の外の経験」が必ず先に引用される）

## 6. 点検

部品を足す・直したら、必ず次を実行します（AIを呼ばないので、何度流しても料金はかかりません）。

```
npm run check:results
```

- 部品そのものの点検：数（仕事の内容ごとに顕在型5つ、経験ごとに3つ…）、文字数、終わり方、タグの形、回答IDの書き間違い、書いてはいけない言葉、STEP5 の4つの答えそれぞれに合う仕事があるか、職種名の重なり
- 組み立てた結果の点検：でたらめに作った2万通りの回答で組み立て、3件・顕在型2件・同じ仕事が2回出ない・理由の引用が2つ以上でどれもその人が選んだ回答の言葉・潜在型に潜在型のタグ・週3時間未満で定例の仕事が出ていない、などを確かめる。六角形は、並びが決まりどおりか、途中経過で見せた力が結果で変わっていないか（7章）を確かめ、合う複業の方向の散らばり（6通りの割合）を表示する
- テスト用4人（`docs/01-site-build-prompt.md` 10章の3人＋回答が少ないDさん）の結果を表示し、全文を `.persona-results/` に保存する
- 「直すところ」が0件なら「点検: 問題なし」と出る。「注意」（一度も選ばれなかった仕事など）は、直さなくても動く

ひとつの仕事のタイプだけ点検するときは `ONLY=office npm run check:results`（PowerShell なら `$env:ONLY='office'; npm run check:results`）。

## 7. 強みの六角形（6つの力）と、合う複業の方向

要件定義（複業アカデミー様・2026-10-29 版）の R13・R11 に合わせて、2026-10-31 に足した。中身は `src/lib/radar.ts`。

- **6つの力**：対人力（人と話す・頼られる）／仕組み化（整える・回す）／企画力（ゼロから形にする）／発信力（前に出る・伝える）／継続力（長く続ける）／専門性（経験の深さ）。名前と説明は要件定義4章の案のまま。六角形の並びは、上から時計回りにこの順（途中経過で見せる順にして、描きかけの形が隣どうしで広がるようにした。要件定義の図の並びは「例」なので変えてよい）
- **いつ見せるか**：途中経過は STEP3 の後の1回だけで、対人力・仕組み化・企画力・発信力の4つを見せる。継続力・専門性は結果画面で見せる（2026-11-10 の打ち合わせ「途中経過は1回まで」。それまでは STEP2・3・4 の後の3回）。表の「点数に使う範囲」は、その STEP までの設問だけで点を決めるという意味
- **決め方**：選んだ選択肢ごとに点を足し、力ごとの「満点の目安」（cap）で割って 1〜5 にする（1 + 4 ×（点 ÷ 目安）² を四捨五入。目安を超えたら 5、0点なら 1）。2乗するのは、中くらいの力を低めに出して、強い力だけを六角形でとがらせるため（2026-11-10 の打ち合わせで「とがらせて強みをわかりやすく」となり、それまでの割合どおりから変えた。曲がり具合は `radar.ts` の SHARPNESS）。六角形では、いちばん高い力の点を大きく・名前をオレンジにし、結果画面の一覧にも「いちばんの強み」と出す。**それぞれの力は、見せる STEP までに答えた設問だけで決める**（あとの答えで、一度見せた形が変わらないように）。点の表は `radar.ts` の PEOPLE・SYSTEM・PLAN・VOICE・KEEP・EXPERT

| 力 | 点数に使う範囲 | 点を足す回答（主なもの） | 目安 |
|---|---|---|---|
| 対人力 | STEP2 まで | 1 人と話す・ケアする仕事（＋2）、2「お客様と信頼関係を築く」（＋2）、3「相談に乗る・話を聞く」（＋2）、4「人から感謝されたとき」「人が成長したとき」（＋1） | 7 |
| 仕組み化 | STEP2 まで | 1 組織を支える・現場を動かす仕事（＋2）、2「仕組みを整える・効率よくする」（＋2）、3「数字やデータをまとめる」「段取りを組む・進行役」（＋2）、4「仕組みがうまく回ったとき」（＋2） | 7 |
| 企画力 | STEP3 まで | 1 企画・発信する仕事（＋2）、2「新しいことを立ち上げる」（＋2）、4「新しいものが形になったとき」（＋2）、5「会社の経営者・社長」（＋1）、6 趣味・地域活動・発信（＋1） | 6 |
| 発信力 | STEP3 まで | 1 企画・発信する仕事（＋2）、1-2「学校・塾・研修講師」（＋2）、3「教える・やり方を伝える」（＋2）、6「SNSやブログでの発信」（＋3） | 6 |
| 継続力 | STEP4 まで | 8-3 を「継続して伴走したい」に寄せるほど（0〜＋4）、7-2 使える時間（3〜5時間＋1、5〜10時間＋2、10時間以上＋3）、7-1「将来の独立に備えたい」（＋1） | 9 |
| 専門性 | STEP5 まで | 9 の深掘りで具体的な答えを選んだ（＋2。「どれも当てはまらない」は0）、8-1 を「会社・組織」に寄せるほど（0〜＋2）、3 の専門的な頼まれごと・5 の会社や利用者の相手（＋1ずつ） | 8 |

- **途中経過の一言**：見せている力のうち、いちばん高いもの（点 ÷ 目安が大きいもの。同じなら六角形の並びで先のもの）の名前と一言を出す（例：「いまのところ、いちばん高いのは「対人力」。人から頼られ、話を聞く力が光っています。」）
- **合う複業の方向**：6つの力のうち、いちばん高いもので決める（6通り）。人と組む伴走型（対人力）／仕組みで支える裏方型（仕組み化）／ゼロから形にする企画型（企画力）／前に出て伝える発信型（発信力）／長く寄り添う継続型（継続力）／経験を深く活かす専門型（専門性）。要件定義 R3「アカデミーが勧めたい複業4〜6種へ着地する」の受け皿として、名前と一言は複業アカデミー様と相談して直す前提の仮のもの
- **散らばりの目安**：でたらめな回答2万通りで、6通りの方向がそれぞれ1〜2割台に散らばるように目安（cap）を決めた（2026-10-31 時点で 12〜25%）。点の表や目安を変えたら `npm run check:results` で散らばりを見る
