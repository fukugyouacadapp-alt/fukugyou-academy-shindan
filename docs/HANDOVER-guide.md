# 複業診断サイト 引継ぎのご案内

2026年11月26日

複業アカデミー様で、診断サイトを引き継いでいただく **ご担当者さま向け** の案内です。
パソコンやプログラムにくわしくなくても読めるように書いています。

※ 実際の作業をする開発者（プログラムを書く人）の方には、別の資料 [開発者向けの引継ぎ資料](HANDOVER.md) をお渡しください。

※ この資料でいう「**引継ぎ元**」は、このサイトを作り、いま管理している開発者のことです。ご質問や、4章で決めていただいたことのお知らせは、これまでどおりのやりとり（メールなど）で引継ぎ元にお送りください。

---

## はじめに：この資料で伝えたいこと

伝えたいことは、次の3つです。

1. 診断サイトが **どんなもので、どう使うか**
2. 引継ぎで **何を受け取るのか**
3. 引継ぎの前に、複業アカデミー様で **決めていただきたいこと**

---

## 1. 診断サイトはどんなものか

### ひとことで言うと

**6つの質問に答えると、その人に合いそうな複業を3つ教えてくれるサイト** です。

- サイトのアドレス： https://fukugyou-academy-shindan.vercel.app
- 質問は、すべて選ぶだけです。文字を打つ必要はありません
- 答え終わると、その人の強みと、合いそうな複業が出てきます

### 3つのうち、2つは「面談で」

- 合いそうな複業は3つ出ますが、**見えるのは1つ目だけ** です
- 残りの2つは、ぼかしをかけて「続きは無料面談で」と書いています
- 面談に申し込んでもらうための仕かけです

### 答えた内容は、どこにも残りません

- 名前やメールアドレスは聞いていません
- 答えた内容は、答えた人のスマホやパソコンの中にだけ一時的に残ります。画面を閉じると消えます
- 複業アカデミー様の側にも、引継ぎ元の側にも、答えた内容は届きません
- そのため、**個人情報が漏れる心配はほとんどありません**

## 2. 講師の方の使い方

面談で残りの2つを伝えるために、**講師だけが開ける専用のページ** があります。

### 使い方の流れ

1. 診断を受けた人の画面には、最後に **診断番号** が出ます
   - 英語と数字が混ざった11文字です（例：G100-6CP8-PAW）
2. 面談を申し込むときに、この番号を講師に伝えてもらいます
3. 講師は、専用のページを開きます
   - アドレス： https://fukugyou-academy-shindan.vercel.app/staff
4. パスワードを入れます
5. 伝えてもらった診断番号を入れて、「結果を見る」を押します
6. **隠していた2つも含めて、3つとも見られます**

### 便利なボタン

- **要点をコピー**：結果の大事なところを写し取れます。面談の記録などに貼り付けられます
- **印刷・PDFに保存**：結果を紙に印刷したり、ファイルにして残したりできます
- **仕事の一覧**（ページの上のほう）：診断で出てくる可能性のある仕事を、全部見られます

### 覚えておいてほしいこと

- 専用のページは、**開くたびにパスワードを聞かれます**。ページを開き直したときも聞かれます。ほかの人にのぞかれないための仕組みなので、故障ではありません
- 入れた番号やパスワードは、ページには残りません

### うまくいかないとき

**「番号から回答を読み取れませんでした」と出る**
→ ほとんどが番号の打ち間違いです。もう一度、番号を確かめてもらってください。
（「I（アイ）」と「1（いち）」、「O（オー）」と「0（ゼロ）」は、どちらで打っても大丈夫です）

**少し前に受け取った番号が開けない**
→ 質問の中身を変えると、変える前の番号は開けなくなります。質問を変えたいときは、面談を待っている人がいないかを先に確かめてください。

**パスワードが通らない**
→ 何回か間違えると、わざと少し待たされます。少し待ってから、ゆっくり打ち直してください。

**パスワードを忘れた**
→ 開発者に頼んで、新しいパスワードにしてもらってください。数分でできます。

## 3. 引継ぎで受け取るもの

診断サイトは、**2つのサービス** を使って動いています。
この2つの持ち主を、引継ぎ元から複業アカデミー様に変えることが「引継ぎ」です。

### ① GitHub（ギットハブ）＝ サイトの設計図をしまっておく場所

- サイトはプログラム（コンピューターへの指示書）でできています。その指示書をしまっておく、ネット上の保管庫です
- サイトを直すとき、開発者はここにある設計図を書き換えます

### ② Vercel（バーセル）＝ サイトを置いて、みんなに見せている場所

- お店にたとえると、**サイトを置いている貸し店舗** のようなものです
- ここに置いてあるから、誰でもスマホやパソコンからサイトを見られます
- 講師用のパスワードも、ここに大事にしまっています

### 引継ぎの作業について

- 持ち主を変える作業は、**引継ぎ元と、複業アカデミー様側の開発者とで行います**。ご担当者さまに作業していただくことはありません
- 作業の途中でサイトが止まるのは、**長くても数分** です
- 引継ぎのあと、サイトを直したいときは、複業アカデミー様側の開発者に頼んでいただく形になります

## 4. 決めていただきたいこと

引継ぎの前に、次の6つを決めてください。

- **いつまでに**：引継ぎの日取りを決める前に。①と②が決まらないと、持ち主を変える作業に入れません。③〜⑥は、引継ぎのあとに決めても大丈夫です
- **どこへ**：決まったものから順に、引継ぎ元へお知らせください。⑤の新しいパスワードだけは、引継ぎ元には送らず、講師の方と開発者の方にだけ伝えてください

### ① 受け取るアカウント（利用者として登録する名前）

- GitHub と Vercel に、**会社としての登録** を用意してください
- 社員の方の個人の登録で受け取ると、その方が会社を離れたときに困ります

### ② Vercel の料金

- Vercel の無料の使い方は、**会社の商売に使ってはいけない決まり** になっています
- 診断サイトは集客に使うので、**有料の使い方（「Pro」という名前の方式）** にしてください
- 料金は、申し込むときに Vercel の案内ページで確かめてください

### ③ 面談の申し込み先

- 結果の画面には、面談を申し込むボタンを出せます
- いまは申し込み先が決まっていないので、ボタンの代わりに「申し込み先は準備中です」と出ています
- 申し込みのページ（申し込みフォームや、LINE公式アカウントなど）が決まったら、そのアドレスを開発者に伝えてください
- アドレスは「https://」から始まるものにしてください

### ④ ボタンに書く言葉

- 決めなければ「無料面談を予約する」と表示されます
- 変えたい場合は、開発者に伝えてください

### ⑤ 講師用のパスワード

- 引継ぎが終わったら、**新しいパスワードに変えてください**
- 変えると、引継ぎ元は講師用のページを開けなくなります
- 新しいパスワードは、講師の方だけに伝えてください

### ⑥ サイトのアドレスを変えるか

- いまのアドレスは「fukugyou-academy-shindan.vercel.app」です
- 会社のアドレス（例：shindan.〇〇.com）にしたい場合は、開発者に頼めば変えられます
- 変えなくても、そのまま使えます

## 5. あとから変えたくなったとき

開発者に頼むときの目安です。

### すぐ変えられること

- 面談の申し込み先と、ボタンに書く言葉
- 講師用のパスワード
- 最初から見せる複業の数（いまは3つのうち1つ）
- 質問の数（いまは6問。前に使っていた9問の形にも戻せます）

### 相談しながら進めたいこと

- 質問の言葉や、選ぶ答えを変える（前に出た番号が開けなくなることがあります）
- 結果に出てくる仕事を増やす・入れ替える
- 結果の文章や、サイトの見た目を変える

### 決めていること（変えるときは社内で確かめてください）

- サイトでは「**複業**」と書き、「副業」とは書いていません
- 「月〇万円稼げる」のような **お金の話** と、**資格がないとできない仕事** は、結果に出さないようにしています

---

## 6. 引継ぎが終わったら確かめること

引継ぎが終わったら、次のことを確かめてください。

- [ ] サイトを開いて、最後まで答えられる
- [ ] 結果の画面に、診断番号が出る
- [ ] 申し込みボタンを押すと、決めた申し込み先が開く（申し込み先を決めた場合）
- [ ] 講師用のページが、新しいパスワードで開ける
- [ ] 診断番号を入れると、3つとも見える
- [ ] 前のパスワードでは開けない
- [ ] GitHub と Vercel の持ち主が、複業アカデミー様になっている
